# Asset collection

Read `manifest.json` for exact paths, dimensions, transparency, aspect ratios, sampled colors, provenance, usage and SHA-256 checksums. Read `../references/logo-usage.md` before choosing or placing a mark.

`originals/` contains all five supplied images with unchanged file bytes and normalized filenames. The manifest records the original upload filenames. `logos/` contains a cropped monogram, a cropped horizontal wordmark and the original transparent circular mark. `artwork/` contains the optional scholars illustration, which is not an official seal.

The opaque-white monogram/wordmark derivatives retain their white background. Do not place them as though transparent. Neither derivative is a vector asset. No recoloring, tracing, reconstruction or generated replacement was performed. Preserve the original aspect ratio.
